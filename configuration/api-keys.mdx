CryptoMCP aggregates data from several specialized crypto APIs, each requiring its own key. All of these providers offer free tiers that are more than sufficient for development and personal exploration — you don't need to enter a credit card to get started. This guide walks you through obtaining a key from each provider and tells you exactly where to paste it.

## Provider Setup Guides

<Accordion title="CoinGecko — Market Data">

### What CoinGecko provides

CoinGecko is the primary market data source for CryptoMCP. It powers real-time prices, 24-hour trading volume, market capitalization, percentage price changes, and token metadata such as name, symbol, and logo.

### Which CryptoMCP tools use it

- `get_price` — live token prices
- `get_market_data` — 24h volume, market cap, price change
- `list_tokens` — search tokens by symbol or name

### How to get your free API key

<Steps>
  <Step title="Create a CoinGecko account">
    Go to [coingecko.com](https://www.coingecko.com) and click **Sign Up** in the top-right corner. Fill in your email and choose a password.
  </Step>
  <Step title="Open the Developer Dashboard">
    After confirming your email, log in and navigate to **Developers → Dashboard** from the top menu, or visit [coingecko.com/en/developers/dashboard](https://www.coingecko.com/en/developers/dashboard) directly.
  </Step>
  <Step title="Generate a new key">
    Click **+ Add New Key**, give it a descriptive name (e.g., `cryptomcp-local`), and click **Create Key**. Your new API key appears in the list.
  </Step>
  <Step title="Copy the key">
    Click the copy icon next to your key and paste it into your `.env` file as the value of `COINGECKO_API_KEY`.
  </Step>
</Steps>

### Free tier limits

The CoinGecko **Demo** (free) plan allows up to **30 calls per minute** and **10,000 calls per month**. CryptoMCP's built-in price caching means you'll rarely come close to this limit during normal use.

</Accordion>

<Accordion title="Etherscan — Ethereum On-Chain Data">

### What Etherscan provides

Etherscan is the authoritative block explorer for Ethereum mainnet. CryptoMCP uses it to read wallet balances, ERC-20 token holdings, transaction details, and raw block data directly from the Ethereum chain.

### Which CryptoMCP tools use it

- `get_wallet_balance` — ETH and ERC-20 token balances
- `get_transaction` — transaction details by hash (Ethereum)
- `get_block` — block details by number or hash (Ethereum)
- `get_gas` — current Ethereum gas price estimates

### How to get your free API key

<Steps>
  <Step title="Register an Etherscan account">
    Go to [etherscan.io](https://etherscan.io) and click **Sign In**, then **Click to sign up**. Enter your username, email, and password.
  </Step>
  <Step title="Verify your email">
    Check your inbox for a confirmation email from Etherscan and click the verification link.
  </Step>
  <Step title="Navigate to API Keys">
    Log in, click your username in the top-right corner, and select **API Keys** from the dropdown, or go to [etherscan.io/myapikey](https://etherscan.io/myapikey).
  </Step>
  <Step title="Create a new API key">
    Click **+ Add**, enter an app name such as `CryptoMCP`, and click **Continue**. Your key is displayed in the table.
  </Step>
  <Step title="Copy the key">
    Click the copy icon and paste the key as `ETHERSCAN_API_KEY` in your `.env` file.
  </Step>
</Steps>

### Free tier limits

Etherscan's free tier supports **5 calls per second** and up to **100,000 calls per day** — well above what CryptoMCP needs for interactive use.

</Accordion>

<Accordion title="Polygonscan — Polygon On-Chain Data">

### What Polygonscan provides

Polygonscan is the block explorer for the Polygon (MATIC) network. It exposes the same data types as Etherscan — wallet balances, token holdings, transactions, and blocks — but for Polygon mainnet.

### Which CryptoMCP tools use it

- `get_wallet_balance` — MATIC and ERC-20 balances on Polygon
- `get_transaction` — transaction details by hash (Polygon)
- `get_block` — block details by number or hash (Polygon)
- `get_gas` — current Polygon gas price estimates

### How to get your free API key

<Steps>
  <Step title="Create a Polygonscan account">
    Visit [polygonscan.com](https://polygonscan.com) and click **Sign In → Click to sign up**. Complete the registration form.
  </Step>
  <Step title="Verify your email">
    Confirm the email Polygonscan sends you before logging in.
  </Step>
  <Step title="Go to API Keys">
    After logging in, select **API Keys** from the user menu or navigate to [polygonscan.com/myapikey](https://polygonscan.com/myapikey).
  </Step>
  <Step title="Add a new key">
    Click **+ Add**, name it `CryptoMCP`, and click **Continue** to generate your key.
  </Step>
  <Step title="Copy the key">
    Paste the key as `POLYGONSCAN_API_KEY` in your `.env` file.
  </Step>
</Steps>

### Free tier limits

Polygonscan's free tier mirrors Etherscan: **5 calls per second** and **100,000 calls per day**.

</Accordion>

<Accordion title="BscScan — BNB Smart Chain On-Chain Data">

### What BscScan provides

BscScan is the block explorer for BNB Smart Chain (formerly Binance Smart Chain). CryptoMCP uses it to retrieve BNB and BEP-20 token balances, transaction data, and block information on BSC.

### Which CryptoMCP tools use it

- `get_wallet_balance` — BNB and BEP-20 token balances on BSC
- `get_transaction` — transaction details by hash (BSC)
- `get_block` — block details by number or hash (BSC)
- `get_gas` — current BSC gas price estimates

### How to get your free API key

<Steps>
  <Step title="Register a BscScan account">
    Go to [bscscan.com](https://bscscan.com) and click **Sign In → Click to sign up**. Fill in your details and submit.
  </Step>
  <Step title="Verify your email">
    Open the verification email from BscScan and confirm your address.
  </Step>
  <Step title="Open the API Keys page">
    Log in, click your username, and choose **API Keys**, or go directly to [bscscan.com/myapikey](https://bscscan.com/myapikey).
  </Step>
  <Step title="Create a key">
    Click **+ Add**, provide a name like `CryptoMCP`, and click **Continue**.
  </Step>
  <Step title="Copy the key">
    Paste the key as `BSCSCAN_API_KEY` in your `.env` file.
  </Step>
</Steps>

### Free tier limits

BscScan's free tier provides **5 calls per second** and **100,000 calls per day**, consistent with the other Etherscan-family explorers.

</Accordion>

<Accordion title="CryptoPanic — Crypto News Headlines">

### What CryptoPanic provides

CryptoPanic is a news aggregator that monitors hundreds of crypto-focused publications, social channels, and official project blogs, then scores each item for sentiment. CryptoMCP uses it to surface relevant headlines through the `get_news` tool.

### Which CryptoMCP tools use it

- `get_news` — latest crypto news headlines with source and sentiment data

### How to get your free API key

<Steps>
  <Step title="Create a CryptoPanic account">
    Go to [cryptopanic.com](https://cryptopanic.com) and click **Sign up** in the top-right corner. Register with your email address.
  </Step>
  <Step title="Open the API section">
    After confirming your email, log in and navigate to **Developers → API** from the site header, or go directly to [cryptopanic.com/developers/api/](https://cryptopanic.com/developers/api/).
  </Step>
  <Step title="Copy your auth token">
    Your personal **Auth Token** is displayed on the API page. Click to copy it and paste it as the value of `CRYPTOPANIC_API_KEY` in your `.env` file. No additional steps are required — the token is active immediately.
  </Step>
</Steps>

### Free tier limits

The CryptoPanic free plan provides access to the news feed API with a rate limit of **1 request per second** and up to **1,000 requests per day**. This is more than sufficient for personal use and development. CryptoMCP’s news caching (`CACHE_TTL_NEWS`, default 300 seconds) keeps calls well within this limit during normal interactive sessions.

</Accordion>

## Finished `.env` with All Keys

Once you've collected your keys from each provider, your `.env` file should look like this:

```bash
# Data provider API keys
COINGECKO_API_KEY=CG-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
ETHERSCAN_API_KEY=ABCDEFGHIJKLMNOPQRSTUVWXYZ123456
POLYGONSCAN_API_KEY=ABCDEFGHIJKLMNOPQRSTUVWXYZ123456
BSCSCAN_API_KEY=ABCDEFGHIJKLMNOPQRSTUVWXYZ123456
CRYPTOPANIC_API_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# Optional: custom RPC endpoints
ETHEREUM_RPC_URL=https://mainnet.infura.io/v3/your_project_id
POLYGON_RPC_URL=https://polygon-mainnet.infura.io/v3/your_project_id
BSC_RPC_URL=https://bsc-dataseed.binance.org/
```

<Note>
CryptoMCP works perfectly with free tier keys for learning, exploration, and personal projects. You only need to upgrade a provider plan if you're building a high-traffic production service that consistently exceeds the free rate limits. Start free, and scale only when your usage demands it.
</Note>
