CryptoMCP is an MCP (Model Context Protocol) server that bridges your AI client — such as Claude Desktop or Cursor — directly to the world's leading cryptocurrency and blockchain APIs. Instead of copying prices from websites or writing custom integrations, you ask your AI assistant natural-language questions and CryptoMCP handles the API calls, data parsing, and response formatting behind the scenes.

## How it works

CryptoMCP runs as a local Node.js process that speaks the Model Context Protocol. Your AI client discovers the server's available tools at startup and calls them automatically whenever you ask a question that requires live data. You never leave your AI client — CryptoMCP fetches, parses, and returns the data inline.

```text
Your AI Client  ──MCP──►  CryptoMCP Server  ──HTTPS──►  Crypto APIs
     ▲                           │
     └───────── structured ──────┘
                 response
```

## Supported networks and data sources

CryptoMCP aggregates data from multiple providers so you get broad coverage with a single configuration:

- **Price & market data** — CoinGecko, CoinMarketCap
- **On-chain data** — Etherscan, Alchemy, QuickNode
- **DeFi protocols** — Uniswap subgraph, The Graph
- **News & sentiment** — CryptoPanic, LunarCrush

<Note>
  CryptoMCP is a learning and exploration project designed to demonstrate how MCP servers can aggregate crypto APIs for AI assistants. It is not intended for production trading systems or financial advice. Always verify critical data against primary sources before making any financial decisions.
</Note>
