These tools let your AI client inspect wallet holdings and discover token contracts across supported EVM networks — useful for portfolio summaries, balance checks, and identifying the correct contract address for a token before querying price or DeFi data.

## `get_wallet_balance`

Returns the native token balance and any ERC-20 token balances held by a wallet address. You can query the native balance alone or pass a list of ERC-20 contract addresses to include specific tokens in the response.

### Parameters

<ParamField body="address" type="string" required>
  The EVM-compatible wallet address to look up. Must be a checksummed or lowercase hexadecimal address starting with `0x`, e.g. `"0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045"`.
</ParamField>

<ParamField body="chain" type="string" default="ethereum">
  The blockchain network to query. Accepts a chain name (`"polygon"`, `"arbitrum"`) or chain ID (`"137"`). See the [supported chains table](/reference/tools/blockchain#supported-chains) for the full list.
</ParamField>

<ParamField body="tokens" type="string[]">
  An optional array of ERC-20 contract addresses whose balances you want included in the response, e.g. `["0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48"]`. When omitted, only the native token balance is returned.
</ParamField>

### Response Schema

<ResponseField name="address" type="string">
  The wallet address as provided, normalised to lowercase.
</ResponseField>

<ResponseField name="chain" type="string">
  The chain name that was queried.
</ResponseField>

<ResponseField name="native_balance" type="object">
  The wallet's balance of the chain's native currency.

  <Expandable title="native_balance fields">
    <ResponseField name="native_balance.symbol" type="string">
      Ticker symbol of the native token, e.g. `"ETH"`, `"MATIC"`, `"BNB"`.
    </ResponseField>
    <ResponseField name="native_balance.raw" type="string">
      Balance in the smallest denomination (wei for ETH), as a string to avoid integer overflow.
    </ResponseField>
    <ResponseField name="native_balance.formatted" type="string">
      Human-readable balance as a decimal string, e.g. `"1.482500000000000000"`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="tokens" type="object[]">
  Array of ERC-20 token balances. Present only when `tokens` was supplied in the request. Each entry contains:

  <Expandable title="token object fields">
    <ResponseField name="tokens[].address" type="string">
      The ERC-20 contract address for this token.
    </ResponseField>
    <ResponseField name="tokens[].symbol" type="string">
      The token's ticker symbol, e.g. `"USDC"`.
    </ResponseField>
    <ResponseField name="tokens[].name" type="string">
      The full token name, e.g. `"USD Coin"`.
    </ResponseField>
    <ResponseField name="tokens[].balance" type="string">
      Human-readable token balance as a decimal string, adjusted for the token's decimals.
    </ResponseField>
    <ResponseField name="tokens[].decimals" type="number">
      The number of decimal places used by this token contract (commonly `6` or `18`).
    </ResponseField>
  </Expandable>
</ResponseField>

### Example Request

```json
{
  "tool": "get_wallet_balance",
  "input": {
    "address": "0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045",
    "chain": "ethereum",
    "tokens": [
      "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
      "0xdAC17F958D2ee523a2206206994597C13D831ec7"
    ]
  }
}
```

### Example Response

```json
{
  "address": "0xd8da6bf26964af9d7eed9e03e53415d37aa96045",
  "chain": "ethereum",
  "native_balance": {
    "symbol": "ETH",
    "raw": "1482500000000000000",
    "formatted": "1.482500000000000000"
  },
  "tokens": [
    {
      "address": "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
      "symbol": "USDC",
      "name": "USD Coin",
      "balance": "4250.000000",
      "decimals": 6
    },
    {
      "address": "0xdAC17F958D2ee523a2206206994597C13D831ec7",
      "symbol": "USDT",
      "name": "Tether USD",
      "balance": "800.000000",
      "decimals": 6
    }
  ],
  "timestamp": "2024-11-14T10:32:00Z"
}
```

<Note>
  `get_wallet_balance` is entirely read-only and only requires a public wallet address. No private keys, seed phrases, or wallet connections are ever needed or accepted by CryptoMCP.
</Note>

## `list_tokens`

Searches the CryptoMCP token registry by name or symbol and returns matching token records, including their contract addresses across chains. Use this tool to resolve a token name to its contract address before calling `get_wallet_balance` or `get_defi_pool`.

### Parameters

<ParamField body="query" type="string" required>
  The search term to match against token names and symbols, e.g. `"usdc"`, `"uniswap"`, or `"USD Coin"`. The search is case-insensitive and supports partial matches.
</ParamField>

<ParamField body="chain" type="string">
  Filter results to a specific chain, e.g. `"polygon"` or `"42161"` for Arbitrum. When omitted, results from all supported chains are returned.
</ParamField>

<ParamField body="limit" type="number" default="10">
  Maximum number of token records to return. Accepts values between `1` and `50`.
</ParamField>

### Response Schema

<ResponseField name="tokens" type="object[]">
  Array of matching token records, ordered by relevance. Each record contains:

  <Expandable title="token object fields">
    <ResponseField name="tokens[].name" type="string">
      The full token name, e.g. `"USD Coin"`.
    </ResponseField>
    <ResponseField name="tokens[].symbol" type="string">
      The token's ticker symbol, e.g. `"USDC"`.
    </ResponseField>
    <ResponseField name="tokens[].contract_address" type="string">
      The ERC-20 contract address for this token on the given chain.
    </ResponseField>
    <ResponseField name="tokens[].chain" type="string">
      The chain name where this contract is deployed.
    </ResponseField>
    <ResponseField name="tokens[].decimals" type="number">
      The number of decimal places the token uses (commonly `6` or `18`).
    </ResponseField>
  </Expandable>
</ResponseField>

### Example Request

```json
{
  "tool": "list_tokens",
  "input": {
    "query": "usdc",
    "limit": 5
  }
}
```

</Tip>
