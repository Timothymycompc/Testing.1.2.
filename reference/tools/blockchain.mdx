These three tools give your AI client direct read access to on-chain data — you can look up individual transactions, inspect block contents, and retrieve real-time gas fee estimates across all supported EVM-compatible networks.

## `get_transaction`

Fetches the full details of a transaction by its hash, including sender, recipient, value transferred, gas consumption, and confirmation status.

### Parameters

<ParamField body="hash" type="string" required>
  The 66-character hexadecimal transaction hash to look up, e.g. `"0xabc123...def456"`. Must include the `0x` prefix.
</ParamField>

<ParamField body="chain" type="string" default="ethereum">
  The blockchain network to query. Accepts a chain name (e.g. `"polygon"`, `"bsc"`) or a chain ID (e.g. `"137"`). See the supported chains table below.
</ParamField>

### Response Fields

<ResponseField name="hash" type="string">
  The transaction hash as provided.
</ResponseField>

<ResponseField name="from" type="string">
  The sender's wallet address.
</ResponseField>

<ResponseField name="to" type="string">
  The recipient's wallet address, or the contract address for contract interactions. `null` for contract deployment transactions.
</ResponseField>

<ResponseField name="value" type="string">
  The amount of native token transferred, expressed as a human-readable decimal string (e.g. `"0.5"`) in the chain's native currency (ETH, MATIC, BNB, etc.).
</ResponseField>

<ResponseField name="gas_used" type="number">
  The amount of gas consumed by the transaction.
</ResponseField>

<ResponseField name="gas_price" type="string">
  The gas price paid, in gwei.
</ResponseField>

<ResponseField name="status" type="string">
  Execution outcome: `"success"` or `"fail"`.
</ResponseField>

<ResponseField name="block_number" type="number">
  The block height at which this transaction was included.
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp of the block that included this transaction.
</ResponseField>

### Example Request

```json
{
  "tool": "get_transaction",
  "input": {
    "hash": "0x5c504ed432cb51138bcf09aa5e8a410dd4a1e204ef84bfed1be16dfba1b22060",
    "chain": "ethereum"
  }
}
```

### Example Response

```json
{
  "hash": "0x5c504ed432cb51138bcf09aa5e8a410dd4a1e204ef84bfed1be16dfba1b22060",
  "from": "0xA1B2C3D4E5F6A1B2C3D4E5F6A1B2C3D4E5F6A1B2",
  "to": "0xF9B2C3D4E5F6A1B2C3D4E5F6A1B2C3D4E5F6F9B2",
  "value": "1.25",
  "gas_used": 21000,
  "gas_price": "22.4",
  "status": "success",
  "block_number": 21190234,
  "timestamp": "2024-11-14T09:17:43Z"
}
```

## `get_block`

Retrieves metadata and summary statistics for a specific block. You can query by block number, block hash, or the special keyword `"latest"` to fetch the most recently produced block.

### Parameters

<ParamField body="block" type="string | number" required>
  The block to retrieve. Pass a block number (e.g. `21190234`), a block hash (e.g. `"0xabc..."`), or the string `"latest"` to fetch the current chain head.
</ParamField>

<ParamField body="chain" type="string" default="ethereum">
  The blockchain network to query. Accepts a chain name or chain ID. See the supported chains table below.
</ParamField>

### Response Fields

<ResponseField name="number" type="number">
  The block height (block number) in the canonical chain.
</ResponseField>

<ResponseField name="hash" type="string">
  The block's unique 32-byte hash.
</ResponseField>

<ResponseField name="parent_hash" type="string">
  The hash of the preceding block, linking the chain together.
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 timestamp of when this block was produced.
</ResponseField>

<ResponseField name="miner" type="string">
  The address of the validator or miner who produced this block.
</ResponseField>

<ResponseField name="transactions" type="number">
  The total count of transactions included in this block.
</ResponseField>

<ResponseField name="gas_used" type="number">
  Total gas consumed by all transactions in the block.
</ResponseField>

<ResponseField name="gas_limit" type="number">
  The maximum gas the block was permitted to consume, as set by the network.
</ResponseField>

### Example Request

```json
{
  "tool": "get_block",
  "input": {
    "block": "latest",
    "chain": "ethereum"
  }
}
```

### Example Response

```json
{
  "number": 21190234,
  "hash": "0xd4e56740f876aef8c010b86a40d5f56745a118d0906a34e69aec8c0db1cb8fa3",
  "parent_hash": "0x5e1c4a5e0f4b1a0b7d8f09c2a3e4b7d8f09c2a3e4b7d8f09c2a3e4b7d8f09c",
  "timestamp": "2024-11-14T10:31:48Z",
  "miner": "0x95222290DD7278Aa3Ddd389Cc1E1d165CC4BAfe5",
  "transactions": 142,
  "gas_used": 14982341,
  "gas_limit": 30000000
}
```

## `get_gas`

Returns current gas fee estimates in three tiers — slow, standard, and fast — so your AI client can help users choose a fee level that balances cost against confirmation speed.

### Parameters

<ParamField body="chain" type="string" default="ethereum">
  The blockchain network to query gas prices for. Accepts a chain name or chain ID. See the supported chains table below.
</ParamField>

### Response Fields

<ResponseField name="base_fee" type="number">
  The current EIP-1559 base fee in gwei. This portion of the fee is burned rather than paid to the miner.
</ResponseField>

<ResponseField name="slow" type="object">
  Fee estimate for transactions willing to wait longer for inclusion.

  <Expandable title="slow fields">
    <ResponseField name="slow.gwei" type="number">Total gas price in gwei for the slow tier.</ResponseField>
    <ResponseField name="slow.estimated_wait_seconds" type="number">Estimated time to confirmation in seconds at the slow tier.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="standard" type="object">
  Fee estimate for typical confirmation times.

  <Expandable title="standard fields">
    <ResponseField name="standard.gwei" type="number">Total gas price in gwei for the standard tier.</ResponseField>
    <ResponseField name="standard.estimated_wait_seconds" type="number">Estimated time to confirmation in seconds at the standard tier.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="fast" type="object">
  Fee estimate for near-instant inclusion in the next block.

  <Expandable title="fast fields">
    <ResponseField name="fast.gwei" type="number">Total gas price in gwei for the fast tier.</ResponseField>
    <ResponseField name="fast.estimated_wait_seconds" type="number">Estimated time to confirmation in seconds at the fast tier.</ResponseField>
  </Expandable>
</ResponseField>

### Example Request

```json
{
  "tool": "get_gas",
  "input": {
    "chain": "ethereum"
  }
}
```

### Example Response

```json
{
  "chain": "ethereum",
  "base_fee": 18.2,
  "slow": {
    "gwei": 19.5,
    "estimated_wait_seconds": 120
  },
  "standard": {
    "gwei": 22.0,
    "estimated_wait_seconds": 30
  },
  "fast": {
    "gwei": 26.8,
    "estimated_wait_seconds": 15
  },
  "timestamp": "2024-11-14T10:32:00Z"
}
```

## Supported Chains

All three tools accept either the chain **name** or the numeric **chain ID** in the `chain` parameter.

| Chain | Name Slug | Chain ID |
|-------|-----------|----------|
| Ethereum | `ethereum` | `1` |
| Polygon | `polygon` | `137` |
| BNB Smart Chain | `bsc` | `56` |
| Arbitrum One | `arbitrum` | `42161` |
| Optimism | `optimism` | `10` |

<Tip>
  Use `"latest"` with `get_block` to quickly check the current block height and confirm that CryptoMCP is connected to a live node for your target chain.
</Tip>

<Warning>
  Gas estimates are point-in-time snapshots and can shift significantly during periods of high network congestion. Always retrieve a fresh estimate immediately before constructing a transaction.
</Warning>
