MCP Prompts are reusable, pre-written instruction templates embedded directly in the CryptoMCP server. When you select one, your AI client automatically fills in the required inputs, orchestrates calls to the relevant CryptoMCP tools in the right order, and formats a polished response — all without you needing to craft the prompt yourself. They're the fastest way to run multi-step crypto workflows that would otherwise require several back-and-forth exchanges.

## How to Use Prompts

<Tabs>
  <Tab title="Claude Desktop">
    <Steps>
      <Step title="Open the attachment menu">
        In the Claude Desktop chat input, click the **paperclip (📎)** icon or press `/` to open the insert menu.
      </Step>
      <Step title="Select a CryptoMCP prompt">
        Scroll to the **CryptoMCP** section and click the prompt you want — for example, **Portfolio Summary**.
      </Step>
      <Step title="Fill in the inputs">
        Claude will surface a short form for any required inputs (e.g., a wallet address or token list). Fill these in and press **Enter**.
      </Step>
      <Step title="Review the output">
        Claude runs the underlying tools automatically and streams a formatted response directly into the conversation.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Other MCP Clients">
    <Steps>
      <Step title="Invoke the prompt by name">
        Call the prompt using your client's `prompts/get` MCP method, passing the prompt name as shown in the listings below (e.g., `portfolio_summary`).
      </Step>
      <Step title="Pass required arguments">
        Supply the required arguments as a JSON object. Each prompt's inputs are documented in the sections below.
      </Step>
      <Step title="Execute the returned messages">
        Your client receives a rendered message array. Feed it to your LLM to produce the final response.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Available Prompt Templates

### Portfolio Summary

Fetch a complete snapshot of a wallet's holdings and their current USD value across any supported chain.

<ParamField body="wallet_address" type="string" required>
  The wallet address to inspect (e.g., `0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045`).
</ParamField>

<ParamField body="chain" type="string" required>
  The chain to query. Must match a `shortName` from `cryptomcp://chains` (e.g., `eth`, `matic`, `arb1`).
</ParamField>

**Tools invoked:** `get_wallet_balance` → `list_tokens` (to resolve symbols) → `get_price` (once per held token)

**Example output:**

```text
Portfolio Summary — 0xd8dA…6045 on Ethereum
Generated: 2024-11-14 09:32 UTC

Token        Balance        Price (USD)    Value (USD)
───────────────────────────────────────────────────────
ETH          2.4810         $3,142.55      $7,797.64
USDC         1,500.00       $1.00          $1,500.00
UNI          45.200         $8.74          $395.05
LINK         120.000        $13.21         $1,585.20
───────────────────────────────────────────────────────
Total Portfolio Value:                     $11,277.89
```

### Market Briefing

Get a concise morning briefing for a watchlist of tokens, combining 24-hour market statistics with the latest headlines.

<ParamField body="tokens" type="string" required>
  Comma-separated list of token symbols to cover (e.g., `BTC,ETH,SOL,AVAX`).
</ParamField>

**Tools invoked:** `get_market_data` (per token) → `get_news` (per token)

**Example output:**

```text
Crypto Market Briefing — 2024-11-14

BTC  $89,204  ▲ 2.3% 24h  Vol: $38.4B
     Headlines: "Bitcoin ETF sees record $1.1B inflow" · "MicroStrategy adds 5,000 BTC"

ETH  $3,142   ▼ 0.8% 24h  Vol: $14.2B
     Headlines: "Ethereum staking yield climbs to 4.2%" · "EIP-7702 moves to CFI status"

SOL  $198.4   ▲ 5.1% 24h  Vol: $4.9B
     Headlines: "Solana DEX volume hits all-time high" · "Firedancer testnet milestone reached"
```

### Gas Tracker

Pull a live cross-chain gas fee comparison across Ethereum mainnet, Polygon, and Arbitrum in a single step.

<Info>
  This prompt requires no inputs. Just invoke it and CryptoMCP immediately fetches current gas fees across all three networks.
</Info>

**Tools invoked:** `get_gas` for `eth`, `get_gas` for `matic`, `get_gas` for `arb1`

**Example output:**

```text
Gas Fee Snapshot — 2024-11-14 09:32 UTC

Network       Slow         Standard     Fast
──────────────────────────────────────────────
Ethereum      18 gwei      22 gwei      28 gwei
               ($1.24)      ($1.51)      ($1.92)
Polygon       32 gwei      40 gwei      55 gwei
               ($0.002)     ($0.003)     ($0.004)
Arbitrum      0.01 gwei    0.01 gwei    0.02 gwei
               ($0.04)      ($0.04)      ($0.08)

💡 Cheapest right now: Arbitrum (Fast = $0.08)
```

### DeFi Scout

Compare liquidity pool yields for a token pair across every supported DEX protocol to find the best place to provide liquidity or swap.

<ParamField body="token_pair" type="string" required>
  The trading pair to scout, formatted as `TOKEN_A/TOKEN_B` (e.g., `ETH/USDC`, `WBTC/USDT`).
</ParamField>

**Tools invoked:** `get_defi_pool` across all indexed protocols for the given pair

**Example output:**

```text
DeFi Scout — ETH/USDC Pool Comparison
Snapshot: 2024-11-14 09:32 UTC

Protocol         Chain        TVL          APR      Volume 24h
──────────────────────────────────────────────────────────────
Uniswap v3       Ethereum     $312.4M      4.82%    $198.2M
Uniswap v3       Arbitrum     $88.1M       5.14%    $62.4M
Curve Finance    Ethereum     $204.7M      3.97%    $44.8M
Balancer v2      Ethereum     $41.2M       3.42%    $9.1M
Aerodrome        Base         $97.3M       6.21%    $38.7M
──────────────────────────────────────────────────────────────
🏆 Best APR: Aerodrome on Base (6.21%)
```

<Tip>
  You don't have to run these prompts in isolation. Ask your AI to chain them — for example, "Run the Portfolio Summary for my address, then give me a Market Briefing for every token I hold." You can also ask the AI to adapt any prompt template on the fly: "Do the same Gas Tracker comparison but also include Base and Optimism."
</Tip>
