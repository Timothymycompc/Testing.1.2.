This guide walks you through installing CryptoMCP, wiring it up to your AI client, and running your very first live crypto query — all in about five minutes. By the end, your AI assistant will be able to answer questions like "What is Bitcoin's current price?" or "Show me the last ten transactions for this wallet address" by calling real blockchain APIs behind the scenes.

## Prerequisites

Before you begin, make sure you have the following ready:

- **Node.js 18 or higher** — [download from nodejs.org](https://nodejs.org)
- **An MCP-compatible AI client** — Claude Desktop, Cursor, or any client that supports MCP servers
- **At least one crypto API key** — a free [CoinGecko](https://www.coingecko.com/en/api) or [CoinMarketCap](https://coinmarketcap.com/api/) key is enough to get started

<Steps>
  <Step title="Clone and install CryptoMCP">
    Clone the CryptoMCP repository and install its dependencies.

    ```bash
    git clone https://github.com/your-org/cryptomcp.git
    cd cryptomcp
    npm install
    ```

    The install step pulls in all required packages including the MCP SDK, API client libraries, and environment helpers. It typically completes in under a minute.
  </Step>

  <Step title="Configure your API keys">
    Copy the example environment file and fill in your API keys.

    ```bash
    cp .env.example .env
    ```

    Open `.env` in your editor and add your keys:

    ```bash
    # .env

    # Required: at least one price/market data provider
    COINGECKO_API_KEY=your_coingecko_key_here
    COINMARKETCAP_API_KEY=your_coinmarketcap_key_here

    # Optional: on-chain data providers
    ETHERSCAN_API_KEY=your_etherscan_key_here
    ALCHEMY_API_KEY=your_alchemy_key_here

    # Optional: news providers
    CRYPTOPANIC_API_KEY=your_cryptopanic_key_here

    # Server config
    MCP_SERVER_PORT=3000
    LOG_LEVEL=info
    ```

    You only need keys for the data sources you plan to use. CryptoMCP will skip providers whose keys are missing and use whichever sources are configured.
  </Step>

  <Step title="Start the MCP server">
    Launch CryptoMCP with the start script:

    ```bash
    npm start
    ```

    Alternatively, run the entry point directly:

    ```bash
    node index.js
    ```

    You should see output similar to the following, confirming the server is ready:

    ```text
    [CryptoMCP] Starting server...
    [CryptoMCP] Loaded tools: get_price, get_market_data, get_wallet_balance,
                              get_transaction, get_block, get_gas, get_defi_pool,
                              get_news, list_tokens
    [CryptoMCP] MCP server listening on stdio
    [CryptoMCP] Ready ✓
    ```
  </Step>

  <Step title="Connect your AI client">
    Tell your AI client where to find the CryptoMCP server. The exact steps vary by client — below are instructions for the two most common options.

    <Tabs>
      <Tab title="Claude Desktop">
        Open your Claude Desktop configuration file. On macOS it lives at `~/Library/Application Support/Claude/claude_desktop_config.json`; on Windows at `%APPDATA%\Claude\claude_desktop_config.json`.

        Add a `cryptomcp` entry inside `mcpServers`:

        ```json
        {
          "mcpServers": {
            "cryptomcp": {
              "command": "node",
              "args": ["/absolute/path/to/cryptomcp/index.js"]
            }
          }
        }
        ```

        Replace `/absolute/path/to/cryptomcp/index.js` with the actual path on your machine, then restart Claude Desktop. You should see a hammer icon (🔨) in the chat interface indicating tools are available.
      </Tab>
      <Tab title="Cursor">
        Open Cursor's settings and navigate to **Features → MCP Servers**. Click **Add Server** and fill in the details:

        - **Name:** `cryptomcp`
        - **Command:** `node`
        - **Args:** `/absolute/path/to/cryptomcp/index.js`

        Save and restart Cursor. CryptoMCP's tools will appear in the available tools panel.
      </Tab>
      <Tab title="Other MCP Clients">
        Any MCP-compatible client that supports stdio transport can connect to CryptoMCP. Point the client at:

        ```json
        {
          "command": "node",
          "args": ["/absolute/path/to/cryptomcp/index.js"]
        }
        ```

        Refer to your client's documentation for the exact configuration format.
      </Tab>
    </Tabs>
  </Step>

  <Step title="Make your first query">
    With CryptoMCP connected, open a new conversation in your AI client and try a few of these prompts:

    ```text
    What is the current price of Bitcoin?
    ```

    ```text
    Show me the 24-hour market data for ETH and SOL.
    ```

    ```text
    What is the ETH balance of wallet 0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045?
    ```

    Your AI assistant calls the relevant CryptoMCP tool, fetches live data, and presents the result inline — no copy-pasting from block explorers required.

    **Example response for the Bitcoin price query:**

    ```text
    The current price of Bitcoin (BTC) is $67,423.18 USD, up 2.4% in the
    last 24 hours. Market cap is approximately $1.33 trillion with a 24-hour
    trading volume of $38.6 billion.
    ```
  </Step>
</Steps>

<Tip>
  For a full list of supported environment variables and instructions for configuring multiple API providers, head to the [Configuration & API Keys](/configuration/api-keys) guide. It covers rate-limit handling, provider fallbacks, and how to set different keys per blockchain network.
</Tip>
