CryptoMCP exposes its capabilities through three building blocks: tools, resources, and prompts. Your AI client discovers these automatically when it connects to the server, and selects the right one based on your natural-language request — you never have to invoke them by name yourself. This page explains what each building block does, which tools are available, and how the data flows from the server back to your assistant.

## Tools

Tools are callable functions. When you ask your AI assistant a question that needs live data — *"What's the market cap of Solana?"* or *"Show me the latest block on Ethereum"* — the assistant selects the appropriate tool, sends it the required parameters, and the CryptoMCP server executes the underlying API call.

### Available Tools

  </Card>
  <Card title="get_market_data" icon="chart-line">

  </Card>
  <Card title="get_wallet_balance" icon="wallet">

  <Card title="get_transaction" icon="arrow-right-arrow-left">

  </Card>

  </Card>
  <Card title="get_gas" icon="gauge">

  </Card>
  <Card title="get_defi_pool" icon="droplet">

  </Card>

  </Card>
  <Card title="list_tokens" icon="list">

### What a Tool Call Looks Like

When your AI decides to call a tool, it sends a structured request to the CryptoMCP server. The server validates the parameters, calls the appropriate data provider, and returns a JSON response the AI uses to formulate its answer.

<Tabs>
  <Tab title="Tool Request">
    ```json
    {
      "tool": "get_price",
      "parameters": {
        "tokens": ["bitcoin", "ethereum"],
        "currency": "usd"
      }
    }
    ```
  </Tab>
  <Tab title="Tool Response">
    ```json
    {
      "bitcoin": {
        "usd": 67420.15,
        "last_updated": "2024-11-15T14:32:00Z"
      },
      "ethereum": {
        "usd": 3581.04,
        "last_updated": "2024-11-15T14:32:00Z"
      }
    }
    ```
  </Tab>
</Tabs>

The AI receives this JSON, interprets it, and replies to you in plain language — something like *"Bitcoin is currently $67,420 and Ethereum is $3,581."*

<Tip>
  You never need to invoke tools manually or write any JSON yourself. Just ask your AI assistant in natural language. It selects the right tool, constructs the correct parameters, and presents the result — all automatically.
</Tip>

## Resources

Resources are data sources the AI can read passively, without performing an action. Think of them as reference material that gives your assistant background context before or alongside a tool call.

CryptoMCP exposes resources such as:

- **Supported tokens list** — a full catalogue of tokens CryptoMCP can look up, including symbols, names, and supported chains.
- **Supported chains** — metadata about every blockchain CryptoMCP is connected to, including chain IDs, native token symbols, and block explorer URLs.
- **Provider status** — current availability and rate-limit headroom for each underlying data provider.

Your AI client can read these resources at any time to answer questions like *"Which blockchains does CryptoMCP support?"* without making an outbound API call.

## Prompts

Prompts are pre-written templates that chain multiple tools together into a single, structured workflow. Instead of your AI making several independent tool calls in sequence, a prompt orchestrates them in the right order and combines the results into a coherent output.

Example prompts included with CryptoMCP:

<AccordionGroup>
  <Accordion title="Token Deep Dive">
    Combines `get_price`, `get_market_data`, and `get_news` to produce a comprehensive snapshot of any token — price, market stats, and the latest headlines — in one response.
  </Accordion>
  <Accordion title="Wallet Summary">
    Uses `get_wallet_balance` alongside `get_price` to value every asset in a wallet and return a total portfolio estimate in your chosen currency.
  </Accordion>
  <Accordion title="Gas & Block Report">
    Pairs `get_gas` with `get_block` to give you the current fee environment alongside the most recent block's stats — useful before submitting a time-sensitive transaction.
  </Accordion>
  <Accordion title="DeFi Pool Screener">
    Calls `get_defi_pool` across multiple pairs and ranks results by TVL or fee APR, so you can quickly identify the most active liquidity pools.
  </Accordion>
</AccordionGroup>

## How the Primitives Work Together

In practice, a single conversation turn can involve all three primitives. Your assistant might read the **supported tokens resource** to confirm a symbol exists, call the **`get_price` tool** for live data, and then apply the **Token Deep Dive prompt** to structure its final answer. CryptoMCP handles the orchestration transparently — from your perspective, you asked one question and got one answer.
