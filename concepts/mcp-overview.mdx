The Model Context Protocol (MCP) is an open standard that lets AI models like Claude call external tools, read live data sources, and execute actions — all without bespoke integrations for every service. Instead of building a custom plugin for each AI client, a single MCP server makes your functionality available to any compatible assistant. CryptoMCP implements this standard to expose the full breadth of crypto and blockchain data as named, callable tools your AI can use the moment you ask.

## How MCP Works

MCP follows a client-server architecture. Your AI assistant acts as the MCP client — it discovers what tools and resources a server offers, then calls them on your behalf as it formulates a response. The server handles authentication, sends requests to the underlying APIs, and streams structured results back to the client.

Here is how a typical CryptoMCP interaction flows:

```
You (natural language)
  → AI Client (Claude, Cursor, etc.)
    → CryptoMCP Server (MCP protocol)
      → Crypto APIs (CoinGecko, Etherscan, DeFi protocols…)
        → Structured JSON response
          → AI Client interprets and answers you
```

You never write a single line of API code. You ask your assistant a question like *"What is the current ETH gas price?"* and the client negotiates with CryptoMCP, calls the right tool, and presents the answer in plain language.

## The Three MCP Primitives

MCP organises server capabilities into three primitives. Understanding them helps you get the most from CryptoMCP.

<CardGroup cols={3}>
  <Card title="Tools" icon="wrench">
    Callable functions the AI invokes to fetch data or trigger actions. CryptoMCP exposes nine tools covering prices, wallets, blocks, DeFi pools, and more. The AI decides which tool to call based on your question.
  </Card>
  <Card title="Resources" icon="database">
    Static or dynamic data sources the AI can read directly — for example, a list of supported tokens or chain metadata. Resources give the AI background context before it calls a tool.
  </Card>
  <Card title="Prompts" icon="message">
    Pre-written prompt templates that combine multiple tools into a coherent workflow. A single prompt can pull prices, news, and on-chain data together and return a structured summary.
  </Card>
</CardGroup>

## Why MCP Instead of Direct API Calls?

Direct API calls require you to manage authentication, rate limits, response parsing, and client-specific integrations for every service you want to use. MCP centralises all of that in one server. Your AI client gets a single, consistent interface regardless of how many underlying data providers CryptoMCP speaks to. When a provider updates its API, you update CryptoMCP — not every client or workflow that depends on the data.
