CryptoMCP lets you look up wallet balances for any public address across major EVM-compatible blockchains. Whether you need to check native token holdings like ETH or MATIC, or want a breakdown of every ERC-20 token in a wallet, the `get_wallet_balance` tool gives you a full picture in a single query — straight from your AI client.

## `get_wallet_balance`

The `get_wallet_balance` tool returns the native token balance and, optionally, the ERC-20 token balances held by a given wallet address. You can scope the query to specific tokens by passing a list of contract addresses, or omit that parameter to retrieve only the native balance.

### Parameters

<ParamField query="address" type="string" required>
  The public wallet address to query (e.g., `"0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045"`). ENS names are also supported on chains where ENS resolution is available.
</ParamField>

<ParamField query="chain" type="string" default="ethereum">
  The blockchain network to query. Accepted values include `"ethereum"`, `"polygon"`, `"bsc"`, `"arbitrum"`, and `"optimism"`.
</ParamField>

<ParamField query="tokens" type="array">
  An optional list of ERC-20 contract addresses to include in the balance response. If omitted, only the native token balance is returned.

  ```json
  ["0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48", "0xdAC17F958D2ee523a2206206994597C13D831ec7"]
  ```
</ParamField>

### Example

Ask your AI **"What tokens does wallet 0xd8dA6B... hold on Ethereum?"** and CryptoMCP calls:

```json
{
  "tool": "get_wallet_balance",
  "parameters": {
    "address": "0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045",
    "chain": "ethereum",
    "tokens": [
      "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
      "0xdAC17F958D2ee523a2206206994597C13D831ec7"
    ]
  }
}
```

The tool returns:

```json
{
  "address": "0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045",
  "chain": "ethereum",
  "native_balance": {
    "symbol": "ETH",
    "balance": "4.812903"
  },
  "tokens": [
    {
      "contract": "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
      "symbol": "USDC",
      "name": "USD Coin",
      "balance": "1500.00",
      "decimals": 6
    },
    {
      "contract": "0xdAC17F958D2ee523a2206206994597C13D831ec7",
      "symbol": "USDT",
      "name": "Tether USD",
      "balance": "250.00",
      "decimals": 6
    }
  ]
}
```

### Response Fields

<ResponseField name="address" type="string">
  The queried wallet address, echoed back from your request.
</ResponseField>

<ResponseField name="chain" type="string">
  The blockchain network that was queried.
</ResponseField>

<ResponseField name="native_balance" type="object">
  An object containing the wallet's native token balance.

  - `symbol` — the native currency symbol (e.g., `"ETH"`, `"MATIC"`)
  - `balance` — the balance as a decimal string to preserve precision
</ResponseField>

<ResponseField name="tokens" type="array">
  An array of ERC-20 token balance objects. Each entry includes:

  - `contract` — the token's contract address
  - `symbol` — the token ticker symbol
  - `name` — the full token name
  - `balance` — the human-readable balance as a decimal string
  - `decimals` — the token's decimal precision as defined in its contract
</ResponseField>

---

<Warning>
  CryptoMCP is a **read-only** data tool. It queries public blockchain state and never has access to your private keys, seed phrases, or the ability to sign or broadcast transactions. Your funds cannot be moved or modified through CryptoMCP under any circumstances.
</Warning>

## `list_tokens`

Before you can query an ERC-20 token balance, you need its contract address. The `list_tokens` tool lets you search for tokens by name or symbol and retrieve verified contract addresses across supported chains.

### Parameters

<ParamField query="query" type="string" required>
  A search string matching a token's name or symbol (e.g., `"USDC"`, `"Uniswap"`, `"wrapped ether"`).
</ParamField>

<ParamField query="chain" type="string">
  Filter results to a specific chain. If omitted, results are returned across all supported chains.
</ParamField>

### Example

Ask your AI **"Find the contract address for USDC on Ethereum"** and CryptoMCP calls:

```json
{
  "tool": "list_tokens",
  "parameters": {
    "query": "USDC",
    "chain": "ethereum"
  }
}
```

The tool returns a list of matching tokens:

```json
{
  "results": [
    {
      "name": "USD Coin",
      "symbol": "USDC",
      "contract": "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
      "chain": "ethereum",
      "verified": true
    },
    {
      "name": "USD Coin (Bridged)",
      "symbol": "USDC.e",
      "contract": "0xFF970A61A04b1cA14834A43f5dE4533eBDDB5CC8",
      "chain": "arbitrum",
      "verified": true
    }
  ]
}
```

<Tip>
  Always use the `verified: true` token entries when passing contract addresses to `get_wallet_balance`. Unverified tokens may be impersonators or low-liquidity duplicates.
</Tip>
