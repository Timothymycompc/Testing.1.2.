CryptoMCP connects you directly to on-chain data across major EVM-compatible blockchains. You can look up individual transactions by hash, inspect blocks, and fetch real-time gas fee estimates — all through natural language prompts in your AI client, without needing to call block explorers or RPC endpoints manually.

## `get_transaction`

The `get_transaction` tool retrieves the details of a specific transaction using its hash. Use it to confirm transfers, inspect contract interactions, or verify that a transaction has been finalized on-chain.

### Parameters

<ParamField query="hash" type="string" required>
  The full transaction hash to look up (e.g., `"0xabc123..."`).
</ParamField>

<ParamField query="chain" type="string" default="ethereum">
  The blockchain network to query. See [Supported Chains](#supported-chains) below for accepted values.
</ParamField>

### Example

Ask your AI **"Look up transaction 0xabc123... on Ethereum"** and CryptoMCP calls:

```json
{
  "tool": "get_transaction",
  "parameters": {
    "hash": "0xabc123def456abc123def456abc123def456abc123def456abc123def456abc1",
    "chain": "ethereum"
  }
}
```

The tool returns:

```json
{
  "hash": "0xabc123def456abc123def456abc123def456abc123def456abc123def456abc1",
  "from": "0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045",
  "to": "0xAb5801a7D398351b8bE11C439e05C5B3259aeC9B",
  "value": "1.25",
  "value_currency": "ETH",
  "gas_used": 21000,
  "status": "success",
  "block_number": 21083741,
  "timestamp": "2024-11-15T13:47:52Z"
}
```

### Response Fields

<ResponseField name="hash" type="string">
  The transaction hash, echoed back from your request.
</ResponseField>

<ResponseField name="from" type="string">
  The wallet address that initiated the transaction.
</ResponseField>

<ResponseField name="to" type="string">
  The recipient wallet address or contract address.
</ResponseField>

<ResponseField name="value" type="string">
  The amount of native currency transferred, expressed as a decimal string to avoid precision loss.
</ResponseField>

<ResponseField name="value_currency" type="string">
  The native currency symbol for the chain (e.g., `"ETH"`, `"MATIC"`, `"BNB"`).
</ResponseField>

<ResponseField name="gas_used" type="number">
  The amount of gas consumed by the transaction.
</ResponseField>

<ResponseField name="status" type="string">
  Transaction outcome — either `"success"` or `"failed"`.
</ResponseField>

<ResponseField name="block_number" type="number">
  The block number in which the transaction was included.
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 UTC timestamp of the block that included this transaction.
</ResponseField>

## `get_block`

The `get_block` tool retrieves metadata about a specific block by its number or hash. You can also pass `"latest"` to get the most recently confirmed block on a chain.

### Parameters

<ParamField query="block" type="number | string" required>
  The block number (e.g., `21083741`) or block hash to retrieve. Pass `"latest"` to fetch the most recent block.
</ParamField>

<ParamField query="chain" type="string" default="ethereum">
  The blockchain network to query.
</ParamField>

### Example

Ask your AI **"What's in the latest Ethereum block?"** and CryptoMCP calls:

```json
{
  "tool": "get_block",
  "parameters": {
    "block": "latest",
    "chain": "ethereum"
  }
}
```

The tool returns:

```json
{
  "number": 21083741,
  "hash": "0xblockhashexample1234567890abcdef1234567890abcdef1234567890abcdef",
  "timestamp": "2024-11-15T14:20:00Z",
  "transaction_count": 184,
  "miner": "0x95222290DD7278Aa3Ddd389Cc1E1d165CC4BAfe5"
}
```

### Response Fields

<ResponseField name="number" type="number">
  The block height (block number) on the chain.
</ResponseField>

<ResponseField name="hash" type="string">
  The unique hash identifier for this block.
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 UTC timestamp of when the block was produced.
</ResponseField>

<ResponseField name="transaction_count" type="number">
  The total number of transactions included in the block.
</ResponseField>

<ResponseField name="miner" type="string">
  The address of the validator or miner that produced the block.
</ResponseField>

## `get_gas`

The `get_gas` tool returns real-time gas fee estimates for a given chain, broken into slow, standard, and fast tiers. Use it to help decide the right gas price before submitting a transaction or to monitor network congestion.

### Parameters

<ParamField query="chain" type="string" default="ethereum">
  The blockchain network for which to fetch gas estimates.
</ParamField>

### Example

Ask your AI **"What are the current Ethereum gas fees?"** and CryptoMCP calls:

```json
{
  "tool": "get_gas",
  "parameters": {
    "chain": "ethereum"
  }
}
```

The tool returns:

```json
{
  "chain": "ethereum",
  "unit": "gwei",
  "slow": 12,
  "standard": 18,
  "fast": 27,
  "timestamp": "2024-11-15T14:23:55Z"
}
```

### Response Fields

<ResponseField name="chain" type="string">
  The blockchain network queried.
</ResponseField>

<ResponseField name="unit" type="string">
  The unit for all fee values — always `"gwei"` for EVM chains.
</ResponseField>

<ResponseField name="slow" type="number">
  Estimated gas price (in gwei) for low-priority transactions. Suitable when confirmation time is not urgent.
</ResponseField>

<ResponseField name="standard" type="number">
  Estimated gas price for average-priority transactions, expected to confirm within a few blocks.
</ResponseField>

<ResponseField name="fast" type="number">
  Estimated gas price for high-priority transactions, targeting next-block inclusion.
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 UTC timestamp when the gas estimate was fetched.
</ResponseField>

## Supported Chains

CryptoMCP's on-chain tools support the following networks. Use the **Chain ID** value for the `chain` parameter:

| Network       | Chain ID       |
|---------------|----------------|
| Ethereum      | `ethereum`     |
| Polygon       | `polygon`      |
| BNB Chain     | `bsc`          |
| Arbitrum One  | `arbitrum`     |
| Optimism      | `optimism`     |

Additional chains may be available depending on your CryptoMCP plan. Contact support if you need a chain not listed here.

---

<Note>
  Free-tier API keys for block explorer providers like Etherscan have rate limits — typically 5 requests per second. If you're querying on-chain data frequently or in bulk, consider upgrading to a paid provider key in your CryptoMCP settings to avoid throttling errors.
</Note>
