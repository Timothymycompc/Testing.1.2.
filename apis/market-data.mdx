CryptoMCP gives you instant access to live cryptocurrency market data through your AI client. Whether you need a quick price check or a full market snapshot — including volume, market cap, and 24-hour price movements — the `get_price` and `get_market_data` tools have you covered, no manual API setup required.

## `get_price`

The `get_price` tool fetches the current spot price of one or more tokens in your chosen fiat or stablecoin currency. It returns a lightweight response focused purely on price, making it ideal for quick lookups or price-alert workflows.

### Parameters

<ParamField query="symbol" type="string" required>
  The ticker symbol of the token you want to price (e.g., `"ETH"`, `"BTC"`, `"SOL"`). Pass a comma-separated list to fetch multiple tokens at once (e.g., `"ETH,BTC,SOL"`).
</ParamField>

<ParamField query="currency" type="string" default="USD">
  The currency in which to express the price. Accepts ISO 4217 fiat codes (e.g., `"EUR"`, `"GBP"`) and common stablecoin symbols (e.g., `"USDT"`, `"USDC"`).
</ParamField>

### Example

Ask your AI client something like **"What is the ETH price?"** — CryptoMCP translates this into the following tool call:

```json
{
  "tool": "get_price",
  "parameters": {
    "symbol": "ETH",
    "currency": "USD"
  }
}
```

The tool returns a JSON response like this:

```json
{
  "symbol": "ETH",
  "price": 3412.07,
  "currency": "USD",
  "timestamp": "2024-11-15T14:23:10Z"
}
```

### Response Fields

<ResponseField name="symbol" type="string">
  The token ticker symbol, uppercased (e.g., `"ETH"`).
</ResponseField>

<ResponseField name="price" type="number">
  The current spot price of the token expressed in the requested currency.
</ResponseField>

<ResponseField name="currency" type="string">
  The currency used for the price value, matching your request parameter.
</ResponseField>

<ResponseField name="timestamp" type="string">
  ISO 8601 UTC timestamp indicating when the price was last fetched from the upstream data provider.
</ResponseField>

## `get_market_data`

The `get_market_data` tool returns a comprehensive market snapshot for a token, including its current price, total market capitalization, 24-hour trading volume, and both absolute and percentage price change over the last 24 hours. Use this tool when you need more context than a raw price — for example, when evaluating volatility or comparing market size across assets.

### Parameters

<ParamField query="symbol" type="string" required>
  The ticker symbol of the token (e.g., `"BTC"`, `"LINK"`).
</ParamField>

<ParamField query="currency" type="string" default="USD">
  The currency for all returned monetary values. Accepts ISO 4217 fiat codes and major stablecoin symbols.
</ParamField>

### Example

Ask your AI client **"Give me the full market data for BTC"** and CryptoMCP calls:

```json
{
  "tool": "get_market_data",
  "parameters": {
    "symbol": "BTC",
    "currency": "USD"
  }
}
```

The tool returns:

```json
{
  "symbol": "BTC",
  "price": 91240.55,
  "market_cap": 1798342901024,
  "volume_24h": 48203847291,
  "price_change_24h": 1340.22,
  "price_change_pct_24h": 1.49
}
```

### Response Fields

<ResponseField name="symbol" type="string">
  The token ticker symbol, uppercased.
</ResponseField>

<ResponseField name="price" type="number">
  The current spot price in the requested currency.
</ResponseField>

<ResponseField name="market_cap" type="number">
  Total market capitalization: circulating supply multiplied by the current price, expressed in the requested currency.
</ResponseField>

<ResponseField name="volume_24h" type="number">
  Aggregate trading volume across tracked exchanges over the past 24 hours, in the requested currency.
</ResponseField>

<ResponseField name="price_change_24h" type="number">
  Absolute price change over the last 24 hours in the requested currency. A negative value indicates a price decrease.
</ResponseField>

<ResponseField name="price_change_pct_24h" type="number">
  Percentage price change over the last 24 hours. A negative value indicates a price decrease.
</ResponseField>

## Data Providers

<Note>
  CryptoMCP uses **CoinGecko** as its primary market data provider, giving you coverage across thousands of tokens and hundreds of exchanges. Depending on your plan, additional providers may be available to improve data freshness or add coverage for niche assets.
</Note>

## Natural Language Queries to Try

<Tip>
  You can ask your AI client in plain English — CryptoMCP handles the rest. Here are some prompts to get you started:

  - *"What is the current price of SOL in EUR?"*
  - *"Show me Bitcoin's market cap and 24-hour volume."*
  - *"Is ETH up or down today?"*
  - *"Compare the prices of ETH, BTC, and BNB in USD."*
  - *"What's the percentage change for LINK in the last 24 hours?"*
</Tip>
